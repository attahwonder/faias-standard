# FAIAS — Independent Review Question (IRQ) Register

Primary unit: the Independent Review Question. IDs: IRQ-<DOM>-NNN, grouped by subdomain. Applicability: G = generative, A = agentic, P = predictive. Every IRQ passed the four-test inclusion discipline (AI-specific blind spot; evidenced harm mechanism; answerable in dev/test; informs a governance or deployment decision) and is answerable via documentation review, non-production testing, or interviews. The Control Objective column summarises each canvas's assurance objective (canvas field 8); where the two differ, field 8 governs.
